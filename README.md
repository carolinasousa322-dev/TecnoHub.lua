# TECNO HUB V1

Script Lua para Roblox, com módulos voltados ao jogo Blox Fruits.

## Recursos identificados no trecho enviado

-   **Level Farm:** procura inimigos compatíveis com o nível do jogador.
-   **Quest Farm:** contém dados de missões do Primeiro Mar.
-   **Boss Farm:** procura e seleciona chefes configurados para cada
    mar.
-   **Mastery Farm:** permite selecionar o tipo de arma usado no farm.
-   **Fruit Mastery Farm:** possui seleção de habilidades Z, X, C, V e
    F.
-   **Material Farm:** procura um tipo de inimigo escolhido.
-   **Chest Farm:** procura baús próximos.
-   **Observation Farm (experimental):** aproxima o personagem de
    inimigos sem atacar.
-   **Sea Events Farm (experimental):** procura alvos de eventos
    marítimos.
-   **Configurações do jogador:** inclui opções de velocidade, pulo,
    salto infinito e noclip.
-   **Combate:** inclui opções de Haki, equipar arma e ataque
    automático.

## Configurações

O trecho apresenta opções editáveis para arma, velocidade de movimento,
altura, distância de aproximação, Haki automático, equipamento
automático e ataque automático.

## Avisos e limitações

-   Os dados de missões apresentados são apenas do Primeiro Mar.
-   Nomes de inimigos, chefes, objetos e coordenadas precisam ser
    conferidos no jogo.
-   Os recursos marcados como experimentais podem não funcionar como
    esperado.
-   Alguns serviços e métodos podem não estar disponíveis em todos os
    ambientes de execução.
-   O código enviado termina no meio da função `setFarm`; portanto, este
    README descreve somente o trecho recebido. A interface e o restante
    do funcionamento não puderam ser verificados.
-   Use apenas de acordo com as regras da experiência e da plataforma.
